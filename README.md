# Bot de Aquecimento de números!

Esse Bot possui um executável, mas é preciso ter instalado na máquina NODE e NPM!
Ele não vai rodar sem isso instalado...

Falando de funcionalidade, ao clicar, ele vai abrir um prompt para rodar a porta local, e entregar o site já para você.
Aponte para o QR CODE e conecte seu Whatsapp nele, entre no LINK, coloque o número para o qual enviará as mensagens, escreva no campo ideal qual será a mensagem enviada e que seja uma por linha!

Bote para rodar e seja feliz!
